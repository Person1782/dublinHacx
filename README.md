# NeedMap — Dublin HacX 2026

NeedMap helps community members report local needs and helps organizers view, prioritize, and respond to them in one dashboard.

## The problem
Community needs—such as food support, supplies, transportation, or emergency assistance—can be difficult to report and coordinate quickly.

## Our solution
NeedMap provides:
- A community-facing site for submitting or viewing needs
- A dashboard for organizers to track reported needs
- Firebase-backed data handling
- A live web deployment

## Tech stack
- HTML, CSS, JavaScript
- Firebase
- React / TypeScript / Vite
- Vercel

## Demo
[Live site](https://dublin-hacx-five.vercel.app)

## How it works
1. A community member submits a need.
2. The request is saved to the system.
3. Organizers view needs in the dashboard.
4. Organizers can prioritize and respond to requests.
